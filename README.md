# COSMOS — Cognitive Mission Intelligence Platform

**An AI-assisted platform for satellite telemetry monitoring, mission intelligence, and decision support.**

## 1. Project Overview

COSMOS (Cognitive Mission Intelligence Platform) is an AI-assisted mission intelligence platform designed to help mission engineers monitor satellite health, understand telemetry, identify potential anomalies, simulate mission scenarios, and support operational decisions.

COSMOS is designed as an augmentation layer for existing mission operations infrastructure. It aims to follow a continuous intelligence workflow:

**Observe → Understand → Predict → Decide → Learn**

The current prototype uses simulated satellite telemetry and does not connect to or control real spacecraft.

## 2. Project Objectives

- Collect and store satellite telemetry.
- Validate and standardize telemetry data.
- Monitor satellite health through a live dashboard.
- Generate alerts when telemetry crosses defined thresholds.
- Support historical telemetry visualization and analysis.
- Provide a foundation for AI-based anomaly detection, prediction, digital twins, and mission decision support.

## 6. Telemetry Parameters

The prototype supports telemetry parameters including:

- Timestamp
- Satellite ID
- Battery voltage
- Battery current
- Battery percentage
- Temperature
- Solar power
- Altitude
- Payload status
- Signal strength

Telemetry is generated by the simulator and stored in PostgreSQL.

## 7. Alert Monitoring

The prototype includes threshold-based alert evaluation.

| Parameter | Condition | Severity |
|---|---|---|
| Battery percentage | Below 30% | CRITICAL |
| Temperature | Above 45°C | WARNING |
| Signal strength | Below 40% | WARNING |

Alerts can be retrieved, acknowledged, and resolved through the backend API.

## 8. Local Setup

### Prerequisites

Install the following:

- Python
- Node.js and npm
- PostgreSQL
- Git
- Visual Studio Code (recommended)

### Step 1 — Clone the repository

```bash
git clone https://github.com/samruddhimandage/COSMOS_FINAL.git
cd COSMOS_FINAL
```

### Step 2 — Configure the backend

Open a terminal in the project root.

Create and activate a virtual environment:

**Windows PowerShell:**

```powershell
python -m venv backend/venv
.\backend\venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
pip install -r backend/requirements.txt
```

### Step 3 — Configure PostgreSQL

Create a PostgreSQL database named:

```text
cosmos_db
```

Configure the database connection in:

```text
backend/.env
```

Use the environment variable names and connection format expected by `backend/app/database/connection.py`.

**Important:** Do not upload your actual database password or other secrets to GitHub.

Create the required database tables and sample satellite record using the database setup instructions maintained by the project team.

### Step 4 — Start the backend

From the project root:

```powershell
cd backend
uvicorn app.main:app --reload
```

Backend address:

http://127.0.0.1:8000

Interactive API documentation:

http://127.0.0.1:8000/docs

### Step 5 — Start the frontend

Open a second terminal:

```powershell
cd frontend
npm install
npm run dev
```

Open the local frontend address displayed by Vite, normally:

http://localhost:5173

### Step 6 — Start the telemetry simulator

Open a third terminal from the project root:

```powershell
.\backend\venv\Scripts\Activate.ps1
python simulator\telemetry_simulator.py
```

The simulator generates telemetry periodically and stores it in PostgreSQL.

## 9. Main API Endpoints

|---|---|---|

## 12. Safety and Scope

COSMOS is currently a development prototype using simulated telemetry.

- It does not connect to real spacecraft.
- It does not issue real spacecraft commands.
- All mission command and decision workflows must remain simulation-only unless separately authorized, validated, and approved through appropriate operational procedures.
- Integration with real mission infrastructure requires documented interfaces, cybersecurity approval, authorization, and extensive validation.
